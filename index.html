⌁ Wi-Fi & Common Issues

Search troubleshooting guides and expand a solution for details.

📶 Wi-Fi won't connect

Check Wi-Fi is enabled, reconnect to the correct campus network and move closer to an access point.

Step-by-step solution
  1. Turn Wi-Fi off and on again.
  2. Forget the campus network and reconnect using the official credentials.
  3. Open a browser in case a sign-in portal is required.
  4. Restart your device. If several users are affected, report it to IT support.

🔐 Campus login or password problem

Check your username, keyboard language and account status.

Step-by-step solution
  1. Use the official campus login page only.
  2. Check Caps Lock and username format.
  3. Use the official password-reset process.
  4. Never share your password or OTP with anyone.

🛡️ WhatsApp spam or suspicious links

Don't click unexpected links or share personal information.

What to do
  1. Do not reply, pay, or share OTPs.
  2. Block and report the account or message in the app.
  3. Tell the group administrator if it happened in a campus group.
  4. If credentials were entered, change them using the official service.

🧰 Internet is slow

Test another website and compare with another device.

Step-by-step solution
  1. Pause large downloads and close unused apps.
  2. Reconnect to Wi-Fi and test again.
  3. Try another browser or device.
  4. Share the time, location and error message with IT support.

🌐 Connected but no internet

The network may require sign-in or may be experiencing an outage.

Step-by-step solution
  1. Open a browser and check for a sign-in page.
  2. Disconnect and reconnect to the official network.
  3. Check whether the same issue affects other devices.
  4. Contact IT support if the problem continues.
